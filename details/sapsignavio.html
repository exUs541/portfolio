SAP Signavio Quick Switch

Switch between SAP Signavio Collaboration Hub and Process Manager while maintaining the current folder or model context.

Overview

SAP Signavio Quick Switch is a productivity browser extension designed to improve navigation efficiency within the SAP Signavio platform. It allows users to switch between the SAP Signavio Collaboration Hub and the Process Manager while maintaining their current folder or model context. Without this extension, switching environments typically redirects users back to the root directory.

Key Features

  • Path-Preserving Navigation Switch environments while staying in the exact same folder or model view.
  • Seamless Integration Adds "Process Manager (Path)" and "Collaboration Hub (Path)" links into the native 3x3 App Launcher.
  • Zero Configuration Works immediately out of the box with no complex setup or Tenant ID requirements.
  • Privacy First Processes URLs 100% locally. Does not collect, transmit, or record any of your process content.

Technical Facts

  • Privacy 100% Local. No data is sent to external servers; everything stays within your Signavio session.
  • Standard Manifest V3 compliant for maximum security and longevity in modern browsers.
  • Performance Zero impact on browser speed. The extension only activates when you are on a Signavio domain.
